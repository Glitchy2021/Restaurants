# Program 2 – Restaurant Tab Program (40 pts.)

You are provided with the design and starter code for a Restaurant Tab Program<br>
The program allows the user to display a list of menu items to order. The user may<br>
order as many items as desired. After all orders have been placed, a tab for the<br>
orders can be generated. The tab should include the added tax and recommended tip<br>
as given in the sample output below.<br>
<br>
You are to use the provided code and do the following:
* Complete and unit test each of the classes of the design (75 pts.)<br>(for a fully functioning program)
* Add six more menu items to the menu (5 pts.)
* Add a new option 2 for displaying only the heart healthy items on the menu (10 pts.)<br>(making Place Order option 3, etc.)
* Allow individual orders to be cancelled (10 pts.)<br>
